# Screenshots and Demo Video Guide

## Screenshots to Take

Take clean screenshots with both browser and terminal visible when useful.

1. **Home Dashboard**
   - Show the page loaded with at least 3 feature requests visible.
   - Show the filter dropdown.

2. **Create Feature Request**
   - Show the form filled in before submission.

3. **Created Feature Request**
   - Show the newly added request appearing in the list.

4. **Edit Feature Request**
   - Show the form in edit mode.

5. **Status Update**
   - Show a status dropdown changed from one state to another.

6. **Filtered View**
   - Show only `Open` or `Completed` requests after applying a filter.

7. **Delete Confirmation / Result**
   - Show the delete flow and the item removed from the list.

8. **Validation Error**
   - Show the frontend rejecting an empty title.

9. **Backend Running**
   - Show the backend terminal with `npm run dev` running successfully.

10. **Database Table**
    - Show the `feature_requests` table in MySQL Workbench or phpMyAdmin.

## Demo Video Structure

Keep the video between 2 and 4 minutes.

### Suggested Flow

1. Introduce the project name and stack.
2. Show the folder structure in VS Code.
3. Show MySQL database and table.
4. Start backend and frontend.
5. Show the dashboard.
6. Add a feature request.
7. Edit a feature request.
8. Change a feature status.
9. Filter by status.
10. Delete a feature request.
11. Show validation by trying to submit an empty title.
12. End by showing GitHub commits and README.

## Recording Tips

- Use OBS Studio, Loom, or Zoom recording.
- Close unnecessary tabs and apps.
- Zoom browser to 110% or 125% so text is readable.
- Speak clearly and avoid rushing.
- Keep your cursor movement slow and intentional.
